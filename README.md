
## 📋 Framework Levels

- **Minimal**: Core dependencies only
- **Standard**: ChittyResolution + ChittyChronicle (recommended)
- **Professional**: Full legal suite (5 apps)
- **Enterprise**: Complete ecosystem (8+ apps)

## 🛠️ Development

The site is the `chittydocs` Cloudflare Worker: static files in `public/` plus registry-backed routes. Cloudflare Workers Builds deploys `main`. See `CLAUDE.md` for commands.
